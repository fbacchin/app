    Repository privati e impostazioni

    Senza token vedi i repository pubblici. Per vedere anche i privati serve un token personale GitHub con permesso repo: resta salvato solo su questo dispositivo, nel browser.

    ● Token attivo: vedi anche i repository privati.
    Con un token attivo l'utente è quello del token e questa impostazione viene ignorata.
    Pagina statica: i dati arrivano direttamente dall'API di GitHub e non passano da altri server.
