# app

Dati e contenuti che le app scaricano: i CSV dei tassi (`Euribor/`), lo stato
del Gottardo (`gotthard/data/`), i codici di gara (`codici/`), i valichi e i
dati di volcano. Si vedono su `https://fbacchin.github.io/app/...`.

Gli indirizzi di questi file sono scritti dentro le app già distribuite:
**non spostarli e non rinominarli**. Li aggiornano la skill `aggiorna-tassi`
e le GitHub Action di questo repo.

## Assistenza e privacy non stanno qui

Le pagine di assistenza e privacy delle app stanno nel repo
[`fbacchin/fbacchin.github.io`](https://github.com/fbacchin/fbacchin.github.io),
cartella `app/`, e si vedono su `https://bacchin.app/app/...`. Come si
aggiornano è spiegato nel
[README di quel repo](https://github.com/fbacchin/fbacchin.github.io#readme).

Qui è rimasto un solo rimando: `Burraco/privacy-burraco.html` (con
`support-burraco.html`), perché Burraco Score 5.0.1 apre ancora quell'indirizzo
dalla schermata «Rimuovi pubblicità». Si cancella quando esce la versione con
il link a bacchin.app (issue Linear ADEV-754). Le app nuove usano solo
indirizzi `https://bacchin.app/app/...`: non aggiungere qui altri rimandi.
