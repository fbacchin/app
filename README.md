# app

Dati e contenuti che le app scaricano: i CSV dei tassi (`Euribor/`), lo stato
del Gottardo (`gotthard/data/`), i codici di gara (`codici/`), i valichi e i
dati di volcano. Si vedono su `https://fbacchin.github.io/app/...`.

Gli indirizzi di questi file sono scritti dentro le app già distribuite:
**non spostarli e non rinominarli**. Li aggiornano la skill `aggiorna-tassi`
e le GitHub Action di questo repo.

## Assistenza e privacy non si modificano qui

I file `support*.html` e `privacy*.html` di questo repo sono solo rimandi
verso `https://bacchin.app/app/...`. Le pagine vere stanno nel repo
[`fbacchin/fbacchin.github.io`](https://github.com/fbacchin/fbacchin.github.io),
cartella `app/`.

Come si aggiornano è spiegato nel
[README di quel repo](https://github.com/fbacchin/fbacchin.github.io#readme).
